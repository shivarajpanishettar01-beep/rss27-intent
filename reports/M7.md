## Decisions and caveats
- **Karamalis implementation is from my reading of the paper, not checked against a reference implementation** (none reachable from this session). Verified properties: values in [0, 1], 1 at the transducer row, 0 at the bottom, row means non-increasing with depth. **Known behaviour**: a fully uncoupled (uniformly dark) frame does *not* get low confidence (mean ≈ 0.44 vs 0.22 coupled), because a homogeneous image lets the walker diffuse freely. Coupling loss is carried by the `s` feature instead. Human to check against the authors' code before using κ_Karamalis in the paper.
- **Proxy** is a ratio I·exp(α·depth)/near-field mean (α = 1) and is not clipped: clipping to [0, 1] saturated it in bright tissue and removed the signal.
- **Vessel ROI** = lumen dilated by 2 px. The anechoic lumen alone carries no adequacy signal, so κ would be blind to the leak.
- **Synthetic leak visibility**: the when-head tests use `attenuation = 150` (hold-world default 60), so adequacy changes are visible in κ. This is a synthetic-world choice for the positive control; the leak-off test uses the same setting.
- **Bin width** Δ = 0.1 s at 10 fps in the synthetic tests (explicit; the config value stays null).
- **Exit-type head**: accuracy 0.82 = the majority class (p_lift = 0.2). The synthetic pre-departure frames contain no exit-type information, so this is the expected result.
- **Timing of late commits** uses counterfactual extension (last bin's features repeated with advancing e), as in M3.
