## Decisions
- **Transitions are a flag**, not a phase: hold chunks that contain the departure must stay `hold` for π̄ to be measurable.
- **Cued holds** = hold start → key press (from `hold_id`/sidecar); contact onset is not separately labelled in cued data (T_onset unknown).
- **Contact without force**: first detected hold start (probe-axis motion has stopped). With `contact_force_n` set, |Fz| above it. The force threshold is a new null config key.
- **Exit type for unlabeled holds**: LIFT if the composed probe-axis displacement over the next H exceeds the tangential one.
- **Passthrough reference** is built from recorded poses only (projection onto the start tool x/y plane + future orientation), independent of the action column.
- **Open-H per-step actions** are derived from the mapped TCP poses (same rule as our converter), since I could not inspect Open-H's action semantics. When the dataset is available, also compare its own action column (human to say what it encodes).
- **Sensitivity**: scaling all thresholds together is not monotone in hold time, because T_hold_min also scales and drops short holds. My first test assumed it was monotone, which was wrong; the test now checks monotonicity in v_hold alone.
