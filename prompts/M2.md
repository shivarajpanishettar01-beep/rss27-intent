# Prompt M2

Implement milestone M2 from docs/BUILD_PLAN.md, following docs/SPEC.md and every rule in CLAUDE.md.

Process:
1. Restate the M2 acceptance tests from docs/BUILD_PLAN.md as a checklist.
2. Write the tests first (synthetic data with known answers where applicable), then the code.
3. Run ruff, mypy and pytest until all pass. Do not weaken a test to make it pass; if a test is wrong, explain why in the report.
4. Write reports/M2.md: what was built, test results (paste the summary), decisions taken on ambiguous points, open questions, anything that needs a human (rig facts, safety, GPU or lab runs).
5. Commit with message "M2: <summary>".

Never invent rig facts; unknowns stay null in configs and the code must refuse to run with them. Never move the physical robot.
