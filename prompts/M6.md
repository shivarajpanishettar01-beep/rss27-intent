# Prompt M6

Implement milestone M6 from docs/BUILD_PLAN.md, following docs/SPEC.md and every rule in CLAUDE.md.

Process:
1. Restate the M6 acceptance tests from docs/BUILD_PLAN.md as a checklist.
2. Write the tests first (synthetic data with known answers where applicable), then the code.
3. Fill the existing stub files in place (docs/LAYOUT.md); do not move or rename files. Run `python scripts/check_structure.py`, ruff, mypy and pytest until all pass. Do not weaken a test to make it pass; if a test is wrong, explain why in the report.
4. Write reports/M6.md: what was built, test results (paste the summary), decisions taken on ambiguous points, open questions, anything that needs a human (rig facts, safety, GPU or lab runs).
5. Commit with message "M6: <summary>".

Never invent rig facts; unknowns stay null in configs and the code must refuse to run with them. Never move the physical robot.

Extra for M6: clone or install Isaac-GR00T and LeRobot at pinned versions and read their fine-tuning entry points and data configs before writing configs. Document exactly where the mode embedding enters the GR00T-H action head. Write scripts/LAB_RUN_M6.md with the GPU commands, the number of runs and a GPU-hour estimate.
